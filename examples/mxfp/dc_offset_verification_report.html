1. Question

Does the real Wan2.2 diffusion model have significant mean offset (DC component) in K and Q that justifies QK smoothing + delta_s correction before FP4 quantization?

2. Method

Instrumented F.scaled_dot_product_attention inside vLLM-Omni's SDPA backend without modifying any model code. Collected per-head statistics from 483 real attention calls during 2 denoising steps (prompt: "Two anthropomorphic cats...")

4. Interpretation

K DC offset is dominant: The mean value across the sequence dimension is 6.4× larger than the token-to-token variation (std). In 58% of head dimensions, the constant offset exceeds the useful signal.

Impact on FP4: E2M1 has only 8 representable magnitudes (0, 0.5, 1, 1.5, 2, 3, 4, 6). If K[dim] has mean=5.0 and std=0.8, all values cluster around 4-6, using just 2 of 8 levels. After centering (subtracting mean), values span [-1.6, +1.6], using all levels effectively.

Q block-mean ratio ~1.8: Within each 128-token group, Q has a bias comparable to its variation. Subtracting it cuts the dynamic range roughly in half.

5. Why delta_s Recovery Works

S = Q @ K^T = (Q_smooth + Q_mean) @ (K_centered + K_mean)^T After smoothing: S_approx = Q_smooth @ K_centered^T Missing term: delta_s = Q_mean @ K_centered^T (computed in FP32 on host) Since K is centered (K_mean = 0): Q_smooth @ K_mean^T = 0 ← vanishes Q_mean @ K_mean^T = 0 ← vanishes ∴ S = S_approx + delta_s ← EXACT (lossless recovery)
