Mixed-Precision MXFP Flash Attention

Analysis on NVIDIA B200 (sm_100) • Qwen3-0.6B • Triton kernel with tl.dot_scaled

1. Problem Statement

Pure MXFP4 (E2M1) attention suffers catastrophic accuracy loss (~25 PPL increase). We investigate mixed-precision: use higher precision for one GEMM and lower for the other.

Two candidates:

  • MXFP8 QK + MXFP4 PV — high precision for attention routing, low for value aggregation
  • MXFP4 QK + MXFP8 PV — low precision for routing, high for value aggregation

2. Mathematical Analysis

Why QK Precision Matters More

Attention: O = softmax(QKT/√d) · V = P · V

QK GEMM error propagation (exponential):

ΔP_ij = P_ij · (ΔS_ij − E_P[ΔS]) ← softmax Jacobian Var(ΔS_ij) ≈ 2σ²_ε · d ← grows with head_dim For d=128, MXFP4 (σ_ε≈0.2): std(ΔS) ≈ 3.2 → KL div ≈ 5.1 (distribution destroyed) For d=128, MXFP8 (σ_ε≈0.04): std(ΔS) ≈ 0.64 → KL div ≈ 0.2 (distribution preserved)

PV GEMM error propagation (linear):

ΔO = ΔP·V + P·ΔV ← linear, bounded by ||P||₁ = 1 No exponential amplification. Errors add noise but don't corrupt routing.

Information-theoretic view: QK determines where to look (routing) — errors cause irreversible information loss. PV determines what to extract — errors cause graceful degradation.

5. Why Synthetic Benchmarks Were Misleading

A synthetic sweep (random inputs, cos_sim vs dequantized reference) showed MXFP4 QK + MXFP8 PV matching MXFP8 accuracy. This was because:

  • Random inputs (randn×0.1) keep logits small → softmax stays flat → QK errors don't cause attention flips
  • Comparing to dequantized inputs only measures kernel numerical error, not quantization impact
  • Real models have sharp attention patterns — small logit noise can flip the argmax and cause catastrophic routing failure

Lesson: Always validate on real model inference, not synthetic random data.

6. Summary

✓ MXFP8 QK + MXFP4 PV RECOMMENDED

  • PPL: +0.20 vs FP16 (negligible)
  • Top-1 accuracy: 86.8%
  • Performance: 1.08x faster than pure MXFP8
  • Worst-case cos_sim: 0.83 (safe)

✗ MXFP4 QK + MXFP8 PV DO NOT USE

  • PPL: +26.6 vs FP16 (catastrophic)
  • Top-1 accuracy: 62.8%
  • Performance: 1.05x faster than pure MXFP8
  • Worst-case cos_sim: -0.21 (inverted!)

VERDICT

Use MXFP8 for QK (attention routing) + MXFP4 for PV (value aggregation)

8% faster than pure MXFP8 with <0.2 PPL increase. QK precision is non-negotiable.
